# MYTHROOT WORLDS — CREATURE LIBRARY CREATION PACKAGE v0.1

## Goal
Build enough canonical exemplar creatures to make the unnamed prehistoric world feel biologically complete. Do NOT attempt a planetary bestiary.

Target: roughly **30–40 canonical exemplars total**, with roughly **15–20 especially important recurring/signature species**.

The desired identity is **prehistoric-esque + scientifically grounded**: big lizards, snakes, heavy beasts, amphibious animals, dangerous predators, etc., without turning everything into dinosaurs or fantasy monsters.

## Core workflow
**CONTINENT → CLIMATE → FUNCTION → EVOLUTIONARY POSSIBILITIES → CREATURE**

Primary library structure:
1. LAND
2. SEA / FRESHWATER
3. AIR

Function is the main design priority.

## Required references
Use the supplied:
- Master World Bible
- Predictive Evolution Matrix
- Creature Necessity Sheet
- Hearth, Shattered, Rift, and Lost continental dossiers
- Flora Function Matrix when vegetation/resources matter

Do not silently invent project canon when a source is unavailable.

## Naming
**Mythroot** is the project/company name. The prehistoric world is **unnamed**. Do not name it.

## Deliverable
Create enough representative creatures to:
- cover essential ecological functions;
- demonstrate multiple evolutionary solutions;
- establish the world's prehistoric biological identity;
- give writers recognizable canonical anchors;
- leave abundant room for future creators to invent additional organisms.
