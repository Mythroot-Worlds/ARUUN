## Rapid-build rule
Do not fill every cell.

1. Identify essential functions.
2. Create a strong exemplar for the most important missing function.
3. Add one or two contrasting solutions where useful.
4. Move on.
5. Return only when an ecological or continental gap appears.

A useful first-pass environment often needs:
- one major herbivore/consumer;
- one smaller consumer/prey form;
- one predator;
- one scavenger/decomposer relationship where relevant;
- one distinctive/signature organism if the region needs it.

This is a guideline, not a quota.

## Cross-environment organisms
Use amphibious animals, coastal hunters, fish-eating land predators, aquatic animals that travel over land, flying animals that feed in water, and migratory species. These efficiently connect ecological systems.
