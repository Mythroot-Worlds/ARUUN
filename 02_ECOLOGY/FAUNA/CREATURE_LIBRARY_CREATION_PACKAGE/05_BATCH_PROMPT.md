# COPY/PASTE BATCH PROMPT FOR CLAUDE

You are helping build the canonical creature library for Mythroot Worlds.

The target is an **unnamed prehistoric-esque world**. Do not name the world.

Your job is NOT to create every species. Create enough representative canonical organisms that the world feels biologically complete and writers understand the kinds of creatures that exist.

## SOURCE OF TRUTH
Use the supplied:
- Master World Bible
- Predictive Evolution Matrix
- Creature Necessity Sheet
- four continental dossiers
- Flora Function Matrix when relevant

Do not silently override project canon. If a source is unavailable, flag the gap.

## CORE FORMULA
**CONTINENT → CLIMATE → FUNCTION → EVOLUTIONARY POSSIBILITIES → CREATURE**

Function is the main priority.

## LIBRARY STRUCTURE
### LAND
Grassland; wetland/floodplain; forest/woodland; dry forest/scrub; arid/desert; highland/mountain; volcanic/disturbed; coastal.

### SEA / FRESHWATER
River; lake/inland sea; wetland; coastal; open ocean; deep water.

### AIR
Forest; grassland; wetland; coastal/marine; mountain; open sky.

Do not fill every category.

## TARGET
Aim for roughly 30–40 canonical exemplars total, with roughly 15–20 especially important recurring/signature species.

## STYLE
Default strongly prehistoric-esque:
big lizards; big snakes; heavy herbivores; dangerous predators; burrowers; armored/tusked/horned beasts; amphibious animals; egg-layers; primitive-feeling aerial organisms; large arthropods where justified.

Do not make everything a dinosaur or everything huge.

Do not avoid Earth-like silhouettes if convergence makes them plausible.

Goal:
**prehistoric feeling + believable evolutionary logic.**

## SCIENTIFIC RULE
For unusual traits, explain:
1. ecological pressure;
2. functional benefit;
3. tradeoff.

Use Favored / Plausible / Difficult / Poor Fit.

## CONTINENTAL LOGIC
Hearth: connected ecosystems, broad ranges, migrations, competition.
Shattered: fragmentation, regional divergence, island specialization, coastal dependence.
Rift: wet/dry transitions, elevation, freshwater, wetlands, volcanic disturbance.
Lost: deep-time isolation, adaptive radiation, convergence, unusual independent lineages.

Do not make every continent contain completely unique fauna. Hearth/Shattered/Rift may share ancestral lineages and variants. Lost may be much more divergent.

## ENTRY
For each canonical exemplar provide:
- Working name
- Continent
- Climate/environment
- Primary function
- Secondary functions
- Body plan
- Approximate scale
- Locomotion
- Diet
- Primary senses
- Defense
- Predation strategy if applicable
- Social behavior
- Reproduction
- Migration/seasonality
- Major ecological relationships
- Evolutionary rationale
- Major tradeoff
- Why it fits the continent
- Why it feels prehistoric-esque
- Writer-facing description

## BATCHING
1. Identify missing essential functions.
2. Identify climate/environment.
3. Run the matrix.
4. Generate several candidate concepts.
5. Select strongest candidates.
6. Avoid duplicate functions/body plans unless contrast is meaningful.
7. Move on.

Do not over-polish one creature while major ecological gaps remain.

## STOPPING RULE
Stop when:
- essential functions are represented;
- major environments have enough examples;
- every continent has meaningful biological anchors;
- multiple evolutionary solutions are demonstrated;
- writers have enough recognizable prehistoric-feeling creatures;
- additional species would mostly be cosmetic variations.

## QUALITY CHECK
Ask:
**Does it have a job?**
**Does the environment explain it?**
**Does the continent explain its history/distribution?**
**Does anatomy have a purpose?**
**Does it have a tradeoff?**
**Does it feel prehistoric without generic dinosaur fantasy?**
**Could a writer use it naturally?**
**Is it distinct from existing creatures?**

If not, revise or discard.

## OUTPUT
Organize the library by LAND, SEA/FRESHWATER, and AIR, then climate/environment.

Mark each:
**CANONICAL EXEMPLAR** or **BACKGROUND ARCHETYPE**.

Do not name the world.
