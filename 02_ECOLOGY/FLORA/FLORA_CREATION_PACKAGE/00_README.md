# MYTHROOT FLORA CREATION PACKAGE v0.1

This package contains two complementary tools:

1. **Flora Function Matrix** — identifies what plants need to do.
2. **Flora Creation Matrix** — turns a selected function + environment into plausible plant designs.

Use them alongside the world/continental dossiers and the existing creature-building framework.

Core philosophy:

> **We are building enough flora to make the world believable, not cataloguing every plant on the planet.**

The flora system should support the fauna system: plants establish food webs, habitat structure, seasonal resources, migration pressures, soil/water behavior, and regional identity.
