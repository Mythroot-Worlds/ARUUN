# MYTHROOT WORLDS — PROJECT CHANGELOG ADDITION
## 2026-08-23 — Hearth / Mountain Settlement & Specialist-Lineage Revision

### Decision
Mountain settlements are now modeled at **50–70 people**. The previously used 60-person midpoint is **not canon** and is no longer a preferred fixed target.

### Structural revision
Because Mountain settlements are smaller than earlier assumptions, specialist lineages are being consolidated into broader houses. Each house will eventually cover multiple related competencies while preserving the existing emphasis on deep specialist knowledge.

The following remain established:
- lineage/house-based specialization;
- same-house/same-specialization marriage;
- annual Mountain Conclave;
- inter-community partner exchange;
- residence according to which community needs the relevant house more.

### Explicitly NOT decided
- exact number of houses;
- exact competency bundles;
- house names;
- population ratios;
- any three-house structure;
- any six-specialization list;
- a fixed 60-person settlement size.
