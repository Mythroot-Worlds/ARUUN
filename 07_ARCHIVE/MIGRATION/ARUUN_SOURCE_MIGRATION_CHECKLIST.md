## Counting rule

Until the full filename inventory is reconciled against the repository tree, the authoritative total remains **84 source files**. The `x` count above is deliberately a **verified-file count**, not a claim that the checklist has already enumerated every source filename.

As each actual source file is uploaded, this document should be updated in the same migration stream: change its status to `[x]`, record its exact repository path, and update the migration summary.

## Preservation rule

Do not delete a source because it is:

- non-canon;
- old;
- superseded;
- contradictory;
- provisional;
- a working model;
- a research/reference document;
- a DOCX;
- or part of a nested package.

If two sources conflict, preserve both and flag the conflict for later creator review.
