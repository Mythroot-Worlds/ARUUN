# ARUUN Discrepancy Log

This is the human-review ledger for continuity findings.

## Rules

- The continuity engine may create findings; it may not decide canon.
- Every accepted/rejected continuity finding should receive a stable review ID.
- A finding is not canonical merely because it appears in this log.
- Resolved findings should record the decision, affected document, and resulting commit.
- Historical material remains available through Git and/or explicit archive storage.

## Status vocabulary

- `OPEN` — requires review.
- `ACCEPTED` — reviewer accepted the proposed continuity interpretation.
- `REJECTED` — reviewer determined the finding is not a canon issue.
- `RESOLVED` — accepted/rejected and the resulting repository state is recorded.
