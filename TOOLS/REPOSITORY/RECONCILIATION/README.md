# ARUUN Reconciliation Layer

The reconciliation layer sits between repository history and canonical worldbuilding.

```text
Git history
   ↓
Continuity engine
   ↓
Overlay + structured findings
   ↓
Human review
   ↓
Discrepancy log
   ↓
Explicit canonical decision
   ↓
Current canon / archive
```

It is intentionally separate from lore. The tools prove and protect the process; they do not dictate the world.
