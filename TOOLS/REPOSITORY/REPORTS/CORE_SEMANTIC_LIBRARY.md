# CORE Semantic Relationship Library

Descriptors are evidence-based relationship language, not forced single classes.

| Color | Identifier | Meaning |
|---|---|---|
| blue | **SUPPORTING** | B provides evidence or context that strengthens or explains A. |
| gold | **HISTORICAL** | The relationship is explained by a change in time, version, or historical state. |
| red | **CONFLICT** | Two claims cannot both be true under the same applicable scope, time, authority, and conditions. |
| green | **COMPLEMENTARY** | Documents cover different dimensions of a larger subject and are more useful together. |
| purple | **SCOPE_SPECIALIZATION** | B applies a broader concept at a narrower, local, organizational, or otherwise specialized scope. |
| gray | **DUPLICATE** | Two artifacts have substantially the same subject, role, scope, and substantive content without a meaningful reason to coexist. |
| teal | **DERIVED** | B is constructed from or summarizes information from A or multiple source artifacts. |
| cyan | **CORROBORATIVE** | B independently provides evidence consistent with a claim in A without merely being a derivative or duplicate. |

## Claim model

`entity + verb + object + modifiers + scope + time + authority + context + source`

## Rule

**VARIANT is not a final resolution.** If evidence does not establish a more specific relationship, the case remains **UNRESOLVED** with a missing-evidence reason.
